# shabbirAlam.github.io

Personal portfolio of **Md Shabbir Alam**, a Staff iOS Engineer based in Bengaluru.

**Live site:** [shabbirAlam.github.io](https://shabbirAlam.github.io)

## About the site

The portfolio presents Shabbir's experience building production iOS applications with Swift, SwiftUI, UIKit, Clean Architecture, concurrency, performance optimization, and secure integrations. It includes:

- Professional experience across Altimetrik, ANAROCK, Infinite Computer Solutions, Fiserv, HSBC, and AQB Solutions
- Technical skills covering architecture, APIs, CI/CD, testing, data, and performance
- Education, contact details, social profiles, WhatsApp, and a resume link

## Technology

- Semantic HTML with inline JavaScript
- CSS with custom properties, responsive layouts, and scroll-reveal animations
- Google Fonts and Font Awesome loaded from CDNs
- GitHub Pages for hosting

There are no build tools, frameworks, package dependencies, or server-side components.

## Local preview

Open `index.html` in a browser:

```bash
open index.html
```

Because the site is static, no development server is required. Review the page at desktop and mobile widths after changing layout or content, and confirm that the profile image, navigation anchors, resume, email, phone, and social links still work.

## Repository layout

| Path | Purpose |
| --- | --- |
| `index.html` | Portfolio markup and inline behavior |
| `styles.css` | Site styling and responsive behavior |
| `resources/profile-picture.jpg` | Profile image |

## Deployment

GitHub Pages deploys automatically when changes are pushed to `main`. The repository must remain named `shabbirAlam.github.io` for the user-site URL to work.
